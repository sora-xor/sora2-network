## Client changes and limits

Clients must refresh metadata and sign for **transaction version 132**. `AuthorizeCall` adds an empty explicit/implicit extension ahead of the existing seven extensions. `System.CodeUpdated` now carries the code hash and changes binary event encoding. `Offences.Offence.timeslot` becomes `slot` with unchanged field encoding. Identity adds call index 24 and event index 22. The compatibility report explicitly records these reviewed changes; raw universal SCALE compatibility is false. Operators need the matching node build before runtime activation.

The custom synchronous staking implementation is preserved. Upstream marks it deprecated in favor of `pallet-staking-async`; moving the VAL payout and deferred-slash design to async staking remains a separate state and economic migration.

Native replay uses scoped production storage and test instrumentation, without whole-chain trie-root or global `try_state` proof. Exact-Wasm execution supplies production runtime behavior checks. Synthetic fixtures and mocked outer transaction signatures are disclosed in the reports; validator heartbeat signatures are actually checked. Already-applied reward and BABE migration markers exercise idempotent production paths, with active historical paths covered by local fixtures.
