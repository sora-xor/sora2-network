        What a halt does

        • Each accepted halt writes a new numbered signal. A worker that has already resumed stops again when it observes the new signal.
        • To resume a stopped worker, its operator must acknowledge the exact digest reported by that node with --bridge-resume-after-observed-halt. Elapsed time and ordinary restarts do not clear the local stop.
        • The guardian signal leaves on-chain bridge calls available. Approvals already submitted can still count toward a quorum, and signed withdrawals can still be redeemed.
        • External contracts and separate relayers have their own stop controls. Check those systems independently.
        • Only guardians can send a halt. The chain enforces a cooldown between accepted signals.
